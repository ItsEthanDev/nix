# README.md

Each project may contain a `README.md`. If one does not exist, ask the user
if they would like to create one.

## Structure of a README

Each README should include the following, but is not limited to

- Title of application
- Brief description of appilcation
- Installation and setup instructions
- Basic Usage instructions

## Example

```md
# My Application

This is a description of my application

# Setup

Here is how you install and setup the project

# Usage

Here is how you use the project
```
